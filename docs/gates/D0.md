## Implemented

- FastAPI `/health`, `/ask`, and safe `/trace/{id}` endpoints.
- Minimal evidence-first HTML UI with source links and citation excerpts.
- Input length/result bounds, in-memory per-client rate limiting, zero-cost
  deterministic retrieval, and an environment kill switch.
- Read-only Docker image definition and local index build path.

## Deployment and rollback

No deployment URL is available. Local smoke testing is required after
installing the optional `app` dependencies. Rollback is the prior immutable
image or prior repository revision; the kill switch disables `/ask` without
changing corpus files.
